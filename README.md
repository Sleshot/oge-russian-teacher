# ОГЭ. Русский — Учительский кабинет

**Максимально полезный сайт-помощник для учителя русского языка и литературы**  
Фокус: подготовка к сочинению 13.3 ОГЭ (и смежные темы).

Репозиторий готов к размещению на **GitHub Pages**.

---

## 🎯 Цель проекта

Создать единый, удобный, профессиональный ресурс, где учитель может:

- Быстро найти определение любого понятия из банка ФИПИ
- Получить готовые аргументы (из текста + литература/жизнь)
- Видеть примеры сочинений на 7 баллов с разбором по критериям
- Работать с текстами (ключевые предложения, микротемы)
- Использовать аудио-версии сочинений (для аудирования / прослушивания)
- Печатать рабочие листы, чек-листы, шаблоны
- Получать готовые методические рекомендации
